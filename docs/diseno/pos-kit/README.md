# Kit CloudPos (referencia visual del rediseño del POS)

- `pantallas/`: 89 PNG a 1x (1194×834) exportados desde la página "Visual Design – Light" del kit.
- `textos/`: textos exactos de las 92 pantallas, extraídos del archivo `.fig` (una tabla por pantalla con
  la ruta de capas y el origen del texto). Sirven para reproducir etiquetas y campos sin abrir Figma.
- El archivo `.fig` (215 MB) no se versiona (`*.fig` en `.gitignore`). Contiene además la página en modo
  oscuro, los componentes, los iconos y 744 imágenes.
